# Security Policy

## Reporting a vulnerability

If you find a security issue in RwandaOS (the live ISO, config scripts,
build tooling, or branding assets), please do **not** open a public issue.

Contact:

- Email: achille@techinika.com (replace with the project's real contact)
- Or open a private security advisory on GitHub once published

## Scope

We consider the following in scope:

- `iso-build/config/` (live-build config, package lists, hooks)
- `scripts/` (build & asset tooling)
- `branding/` assets shipped in the built ISO

## What we do not cover

- Upstream Debian packages (report to Debian Security)
- Google Sans / Debian archive third-party bugs (report upstream)
